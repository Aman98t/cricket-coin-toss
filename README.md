# 🏏 Cricket Coin Toss

A modern interactive cricket coin toss webpage built using HTML, CSS and vanilla JavaScript.

## Features

- Responsive mobile-first design
- Cricket stadium background
- 3D animated coin
- HEAD and TAIL coin faces
- Full coin clickable
- Controlled/demo toss mode
- Random toss mode
- Smooth coin flip animation
- Result reveal animation
- Touch-friendly interface
- No backend required
